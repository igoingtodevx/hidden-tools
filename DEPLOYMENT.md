# Deployment handoff

1. Import this repository into Vercel as a static project.
2. No framework preset or build command is required.
3. Enable proper access protection before adding private data or paid API routes.
4. Add server-side functions for AI tools; keep all API secrets in Vercel environment variables.
5. `noindex` and `robots.txt` reduce discovery but are not authentication.

The current project is static and deploys directly from the repository root.
